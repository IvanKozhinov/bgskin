# BGSkins.pro

Маркет скинов CS2: каталог с живыми ценами, покупка с баланса и выдача предметов
в Steam через трейд-оффер. Работает на [bgskins.pro](https://bgskins.pro).

## Как устроено

Ассортимент и закупка идут через провайдера **Skinsback**: магазин забирает их
прайс-лист (наличие + закупочная цена в USD), пересчитывает в рубли по их же
курсу и продаёт с настраиваемой наценкой. Покупка списывает рубли с баланса
пользователя, а предмет выкупается у провайдера и уходит покупателю трейд-оффером.

- **Next.js 16** (App Router), TypeScript, Tailwind
- **SQLite** (better-sqlite3) — пользователи, заказы, пополнения, настройки
- **Steam OpenID** — вход
- Живая лента покупок через SSE

## Разделы

| Путь | Что это |
|---|---|
| `/` | витрина: топ предметов, живая лента, горячие позиции |
| `/market` | каталог с фильтрами и поиском |
| `/wallet` | баланс и пополнение |
| `/profile` | трейд-ссылка, заказы, история |
| `/admin` | панель: пользователи, цены, интеграции, документы, лайв-лента |

## Запуск

```bash
npm ci
npx tsx scripts/fetch-catalog.ts   # метаданные предметов (картинки, редкость)
npm run build && npm start
```

Минимальная конфигурация в `.env.local`:

```
SITE_URL=https://example.com
SESSION_SECRET=<длинная случайная строка>
ADMIN_USER=admin
ADMIN_PASSWORD=<пароль>
```

Ключи Skinsback и платёжных провайдеров задаются **в панели** (`/admin/integrations`)
и хранятся в базе в зашифрованном виде; переменные окружения работают как
запасной вариант.

## Устройство кода

```
src/app/(site)      витрина (публичные страницы)
src/app/admin       панель администратора
src/app/api         API: каталог, покупка, пополнения, вебхуки, админка
src/lib             каталог, цены, наценка, валюта, Skinsback, БД, сессии
scripts             генерация каталога и артов
```

Ключевые модули: `lib/catalog.ts` (сборка витрины из прайса), `lib/pricing.ts`
(наценка), `lib/currency.ts` (USD→RUB), `lib/skinsback.ts` (клиент API),
`lib/reconcile.ts` (догоняющая сверка статусов заказов).
